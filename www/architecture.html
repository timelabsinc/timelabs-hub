State of the system — 3 flags

Claude is running on empty

The Anthropic balance is unfunded, so the Hermes gateway hits an hourly rate-limit and every Claude call falls back to a free model — weaker on the work that matters most (financial reads, customer copy). This is the single biggest quality lever, and the one thing blocking a first-class Claude presence in Hub.

Fix: fund a small extra-usage balance → the existing /model claude path lights up instantly, zero new code. Or commit to free models and stop the hourly retries.

WhatsApp groups aren't being read

The bridge is connected, but throwing constant "no session to decrypt" errors on group messages — so the order-capture-from-WhatsApp feature is effectively dark (0 orders captured). Classic stale sender-key state after a long-lived session.

Fix: re-link the WhatsApp session (fresh pair) to rebuild group keys, then verify a test order in the group flows into Face → Orders.

2.9 GB of RAM is parked on idle tools

The alook dev cluster (2.9 GB) and postgres (running only for the stopped Paperclip app) are consuming memory and attack surface for zero current benefit — on a 7.8 GB box that's real headroom.

Fix: a keep / kill / productionize decision on each. Retiring both frees ~3 GB immediately and is fully reversible.

What's solid

TLS, Google login, Face, Drop, Ledger, Chat, Key, public shares, Google Drive import, and daily backups are all healthy. The edge is tight — one door, everything behind it authenticated.
